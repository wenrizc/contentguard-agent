# 需求说明

## 用户与业务背景

小影（VivaVideo）内容团队需要将剪辑完成的短视频投放到官方账号或其他运营账号。素材可能带有字幕、配乐、贴纸和特效，发布前要确认素材资料、版权授权、内容安全和排期条件。运营希望 Agent 帮忙查资料和生成草稿，但最终改期决定仍由人确认。

## 用户输入

V1 每个任务单处理一个素材；批量排期拆成多个 `source_request_id` 请求，避免一个时间字段无法表达多个素材的独立冲突和确认状态。时间统一带时区，示例：

```json
{
  "source_request_id": "REQ-001",
  "material_ids": ["M01"],
  "account_id": "official_cn",
  "requested_start": "2026-11-06T18:00:00+08:00",
  "duration_minutes": 30,
  "hard_time": true,
  "conflict_policy": "ask_before_change"
}
```

## 输出要求

每项素材都要返回：审核状态、风险原因和证据、建议时段、待确认项、确认状态、草稿保存状态和 Trace 文件位置。

## 必须满足的验收点

1. 正常排期并保存草稿。
2. 素材信息或版权资料缺失时请求补充，不能默认通过。
3. 规则风险返回证据并阻断排期。
4. 指定时段冲突时查询候选时段，硬性时间不能被擅自改变。
5. 相同请求重复提交只产生一份草稿。
6. 保存失败明确返回失败，不能虚报成功。

## 范围边界

V1 不执行正式发布，不接真实视频审核 API，不处理真实用户隐私素材。视频审核由合成 Mock 服务返回，文本字幕和业务规则由本地确定性逻辑检查。
